# zabbix_proxy (Data Source)

Looks up an existing Zabbix proxy by its technical name.

Attribute names match the [`zabbix_proxy`](../resources/proxy) resource and are
the same on every supported Zabbix version; see that page for how they map onto
the pre-7.0 and 7.0+ forms of the proxy object.

`tls_psk_identity` and `tls_psk` are write-only in the Zabbix API and are
therefore not available from this data source.

`host` is the pre-7.0 name of `name` and is deprecated but still accepted.
Exactly one of `host` or `name` must be given.

## Example Usage

```terraform
data "zabbix_proxy" "existing" {
  name = "proxy-eu-west"
}

resource "zabbix_hostgroup" "example" {
  name = "Remote sites"
}

resource "zabbix_host" "example" {
  host    = "server-1.example.com"
  groups  = [zabbix_hostgroup.example.id]
  proxyid = data.zabbix_proxy.existing.id

  interface {
    type = "agent"
    ip   = "10.0.0.10"
  }
}
```

## Schema

### Optional

- `host` (String, Deprecated) Technical name of the proxy. Deprecated: this is the pre-7.0 property name, use `name` instead. Exactly one of `host` or `name` must be given
- `name` (String) Technical name of the proxy. Exactly one of `host` or `name` must be given

### Read-Only

- `address` (String) Address (IP or DNS name) the server connects to, passive proxies only
- `allowed_addresses` (String) Comma delimited list of addresses the proxy may connect from, active proxies only
- `description` (String) Description of the proxy
- `id` (String) The ID of this resource.
- `local_address` (String) Address (IP or DNS name) that active agents of hosts monitored by the proxy group are redirected to in order to reach this proxy. Required when `proxy_groupid` is set, and must be empty when it is not. Zabbix 7.0 and later
- `local_port` (String) Port that goes with `local_address`. Only a proxy in a proxy group can use anything other than the default. Zabbix 7.0 and later
- `operating_mode` (String) How the proxy and server connect, one of: active, passive (Zabbix calls this "status" before 7.0)
- `port` (String) Port the server connects to, passive proxies only
- `proxy_groupid` (String) ID of the proxy group (`zabbix_proxygroup`) the proxy belongs to, or "0" for none. A proxy in a group needs `local_address`. Zabbix 7.0 and later
- `tls_accept` (String) Encryption accepted from an active proxy, one of: cert, psk, unencrypted
- `tls_connect` (String) Encryption used when the server connects to a passive proxy, one of: cert, psk, unencrypted
- `tls_issuer` (String) Certificate issuer, requires certificate encryption
- `tls_subject` (String) Certificate subject, requires certificate encryption
