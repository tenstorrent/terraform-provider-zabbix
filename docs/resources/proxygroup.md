# zabbix_proxygroup (Resource)

Manages a Zabbix proxy group: a set of proxies that share the monitoring of the hosts assigned to the group, with automatic failover between them. Requires Zabbix 7.0 or later.

## Example Usage

```terraform
# Zabbix 7.0 and later. Hosts monitored by a proxy group are spread across
# its online proxies by the server, and moved when a proxy goes offline.
resource "zabbix_proxygroup" "site" {
  name           = "eu-west"
  description    = "EU West site proxies"
  failover_delay = "1m"
  min_online     = "1"
}
```

## Schema

### Required

- `name` (String) Name of the proxy group, unique across the Zabbix server

### Optional

- `description` (String) Description of the proxy group
- `failover_delay` (String) How long a proxy must be offline (or back online) before the server moves its hosts to another proxy in the group. A time unit between 10s and 15m, such as `30s` or `1m`, or a user macro
- `min_online` (String) Minimum number of online proxies for the group to be considered online, 1 to 1000, or a user macro. A string because Zabbix accepts a macro here

### Read-Only

- `id` (String) The ID of this resource.
